## 次の一手（推奨順）

### 1. X と note で発信する ← いまここ

**費用ゼロ・リスクゼロで需要を測れる、いちばん確実な一歩です。**

文面の下書きは [`docs/PROMOTION.md`](PROMOTION.md) にあります。
まずノウハウ投稿だけを2〜3週間くり返し、反応を見る。
アプリの宣伝はその後。

**確かめたい仮説**：若手の電工が「こんなことも知らないのかと思われるのが怖くて
先輩に聞けない」という痛みを抱えているか。これが当たっていれば、
アプリの重心は「現場トラブル解決」ではなく「匿名Q&A」かもしれません。
現場で若手に「分からんことがあった時、素直に先輩に聞けとる？」と聞いてみてください。

### 2. 招待制クローズドβ

反応があったら、Supabase につないで本物のSNSにします（アカウントは取得済み）。
招待コードを知っている人だけ登録できる形にすれば、炎上リスクがほぼなく、
通報対応の負荷も小さく、いつでも引き返せます。

実装するもの：招待制の会員登録、アクセス解析（Cloudflare Web Analytics・無料）、
ブロック機能、アカウント削除。

構成と手順は [`docs/SETUP.md`](SETUP.md) に記載済み。
Cloudflare Pages ＋ Supabase 無料枠で**月額0円**。

### 3. App Store（ずっと先）

App Store Review Guideline 1.2 により、ユーザー投稿型アプリには
フィルタ・通報・**ブロック**・連絡先公開が必須で、**通報から24時間以内の対応**が
求められます。日中現場に出ている一人運営には重い約束なので、
Webで人が集まってからにするのが確実です。

それまでは PWA（Safariで「ホーム画面に追加」）で、アプリのように使えます。

## 収益について

SNSは規模が出るまで収益ゼロ。これは構造的にそうなります。
まず「赤字にしない」を固めるのが先で、Web公開のみなら**年1,500円**（ドメイン代のみ、
無くても公開可）です。

収益の芽として現実的な順番：

1. **求人掲載** — 電気工事は人手不足で採用単価が高い。会員300〜500人で成立しうる
2. **工具・電材メーカーのタイアップ** — レビュー欄と直結。会員1,000人超から
3. 広告（AdSense）— 月10万PVで月1〜3万円程度。小規模では効率が悪い

**課金開始は最低1年後**を推奨。お金を受け取った瞬間に、特定商取引法に基づく表記
（氏名・住所の公開）、決済手段、返金対応が必要になります。

## 忘れてはいけない注意

- **Supabase の service_role キーは、コードに一切書かないこと。**
  リポジトリが公開設定なので、書いた瞬間に世界中から見えます。
  管理作業は Supabase の管理画面から行うので、そもそも出番はありません。
  アプリに入れてよいのは anon key だけです。
- **モックデータと発信用下書きの技術的内容は AI が生成したものです。**
  公開する前に、必ずご自身の経験で確認・書き換えてください。
- **安全がこのサービス最大のリスクです。** 誤った回答が感電・火災につながり得ます。
  免責の常時表示と危険通報は、規模が小さいうちから外さないでください。
