# 電工コネクト（フロントエンド MVP）

電気工事士に特化した現場SNSのプロトタイプです。外部DBやAPIキーの設定は不要で、
モックデータと React state / LocalStorage だけでひととおりの操作が動きます。

## 起動

```bash
npm install
npm run dev
```

ブラウザで **http://localhost:3000** を開いてください。
PC画面では最大幅 480px のスマホビュー枠が中央に表示されます。

その他のコマンド:

```bash
npm run build   # 本番ビルド（型チェック込み）
npm run lint    # tsc --noEmit による型チェックのみ
```

## 安全設計

電気工事という題材の性質上、誤った回答が感電・火災につながり得ます。
そのため、次の仕組みを「制限」ではなく「投稿の質を上げる仕掛け」として組み込んでいます。

- **確認した項目を先に書かせる** — トラブル投稿では「電源を切って検電した」「検相器で相順を確認した」など、
  現場で確認済みの項目を1つ以上選ばないと投稿できません。断定的な質問が減り、回答も切り分けから入れます
- **免責の常時表示** — 規約の中に埋めず、投稿画面とコメント入力欄の直上に常に表示します
- **扱わない話題の明示** — トラブル投稿時に、活線作業・高圧受電設備の作業手順そのものは扱わない方針を出します
- **危険な内容の通報** — 投稿とコメントのそれぞれに、1タップで押せる専用ボタンを置いています
- **断定しない言葉づかい** — 「これで解決！」ではなく「この方法で直りました（投稿者の報告）」とし、
  客観的な正解ではなく一人の経験報告であることを明示します

- **初回同意フロー** — 起動時に一度だけ、免責と守るべき点を読ませてから同意を取ります
- **削除依頼の窓口** — 権利侵害や情報漏洩の申し立てを受け付ける導線を用意しています

なお現状は試作品のため、通報は送信されずこの端末内に記録されるだけです。
実運用では、サーバー側の受付とモデレーション（AIによる一次スクリーニングを含む）が必要です。

## 技術構成

- Next.js 15（App Router） / TypeScript / React 19
- Tailwind CSS v4、lucide-react
- 状態は `lib/denkou/store.ts` の `useDenkouStore` に集約し、LocalStorage へ自動保存
- 現場写真のダミー画像は `lib/denkou/images.ts` でインライン SVG（data URI）として生成するため、
  ネットワークに一切アクセスしません。アップロードした写真は長辺 900px / JPEG 品質 0.7 に縮小して保存します

## 公開するには

個人運営・収益化なしなら **月額0円**で公開できます。
構成（Cloudflare Pages + Supabase 無料枠）、手順、公開前チェックリスト、
通報の確認方法は [`docs/SETUP.md`](docs/SETUP.md) にまとめています。

データベースの定義は [`supabase/schema.sql`](supabase/schema.sql) にあります。
Supabase の SQL Editor に貼り付けて実行するだけで、テーブルと行単位セキュリティ(RLS)が作られます。

> **公開前に必須**：`lib/denkou/legal.ts` の運営者名と連絡先メールアドレスを実際のものに差し替えてください。
> 削除依頼を受け付ける窓口がないまま公開してはいけません。
